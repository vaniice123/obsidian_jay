# 안티센스 올리고뉴클레오타이드(Antisense Oligonucleotides, ASO)

안티센스 올리고뉴클레오타이드(ASO)는 표적 mRNA에 상보적으로 결합하여 유전자 발현을 조절하는 합성 단일가닥 핵산 치료제이다. RNase H 매개 분해, 스플라이스 스위칭(exon skipping/inclusion), 번역 억제 등 다양한 기전으로 작용하며, FDA 승인 약물 다수가 존재한다. 화학적 변형(PS backbone, 2'-MOE, LNA, PMO 등)을 통해 안정성, 결합력, 약동학을 개선하는 것이 핵심 과제이다.

---

## 작용 기전

### RNase H 매개 분해 (Gapmer)
- DNA 중심부(gap) + 변형 뉴클레오타이드 양 날개(wings)
- RNA/DNA 하이브리드 형성 → RNase H1이 표적 mRNA 절단
- 간독성 위험: 고친화 gapmer에서 RNase H1 의존적 간독성 보고 ([[Jay's Knowledge Base/raw/403-burel-2016-hepatotoxicity-of-high-affinity-gapmer-antisense-o\|raw/403-burel-2016-hepatotoxicity-of-high-affinity-gapmer-antisense-o]])

### 스플라이스 스위칭
- 엑손 스키핑(exon skipping): DMD 치료제 (viltolarsen, eteplirsen) — 돌연변이 엑손 건너뛰기로 truncated dystrophin 생산 ([[Microbiome-KB/raw/384-dhillon-2020-viltolarsen-first-approval\|raw/384-dhillon-2020-viltolarsen-first-approval]], [[Jay's Knowledge Base/raw/391-unknown-2021-antisense-oligonucleotide-mediated-exon-skipping-t\|raw/391-unknown-2021-antisense-oligonucleotide-mediated-exon-skipping-t]])
- Cryptic exon 억제: TDP-43 기능 상실 시 UNC13A, STMN2의 cryptic exon 포함 → ASO로 교정 가능 ([[Jay's Knowledge Base/raw/446-baughn-2023-mechanism-of-istmn2i-cryptic-splice-polyadenylatio\|raw/446-baughn-2023-mechanism-of-istmn2i-cryptic-splice-polyadenylatio]])

### 유전자 발현 활성화 (saRNA)
- Small activating RNA → 표적 유전자 전사 촉진 ([[Microbiome-KB/raw/408-kingwell-2021-small-activating-rnas-lead-the-charge-to-turn-up-g\|raw/408-kingwell-2021-small-activating-rnas-lead-the-charge-to-turn-up-g]])
- 기존 억제 중심 접근과 반대 방향의 치료 전략

## 화학적 변형

| 변형 | 특성 | 대표 약물 |
|------|------|-----------|
| **PS (Phosphorothioate)** | 뉴클레아제 저항, 혈장 단백질 결합 | 대부분의 ASO |
| **2'-MOE** | Tm 상승, 독성 감소 | Nusinersen, Inotersen |
| **PMO (Morpholino)** | 전하 중성, 면역 반응 최소화 | Viltolarsen, Eteplirsen |
| **LNA** | 매우 높은 결합력, 간독성 주의 | — |
| **cEt** | LNA 유사, 독성 개선 | — |

- PS-ASO의 세포 단백질 결합이 치료 효과와 독성 모두에 영향 → 화학적 변형으로 단백질 결합 프로파일 조절 가능 ([[Microbiome-KB/raw/432-shen-2019-chemical-modification-of-ps-aso-therapeutics-reduc\|raw/432-shen-2019-chemical-modification-of-ps-aso-therapeutics-reduc]])
- 차세대 ASO: 세포 내 흡수 역학(kinetics)과 트래피킹 기전이 화학 구조에 따라 상이 ([[Jay's Knowledge Base/raw/466-linnane-2019-differential-uptake-kinetics-and-mechanisms-of-int\|raw/466-linnane-2019-differential-uptake-kinetics-and-mechanisms-of-int]])

- **Nusinersen** (Spinraza): SMA, 척수강 내 투여 ([[Jay's Knowledge Base/raw/467-luu-2017-population-pharmacokinetics-of-nusinersen-in-the-c\|raw/467-luu-2017-population-pharmacokinetics-of-nusinersen-in-the-c]])

- **Viltolarsen** (Viltepso): DMD 엑손 53 스키핑 ([[Microbiome-KB/raw/384-dhillon-2020-viltolarsen-first-approval\|raw/384-dhillon-2020-viltolarsen-first-approval]])
- **Inclisiran**: PCSK9 siRNA, 피하주사, LDL-C 저하 ([[Microbiome-KB/raw/416-lamb-2021-inclisiran-first-approval\|raw/416-lamb-2021-inclisiran-first-approval]])
- 2017-2019년 사이 다수의 올리고뉴클레오타이드 치료제 FDA 승인 ([[Microbiome-KB/raw/394-ruger-2020-oligonucleotides-to-the-gene-rescue-fda-approvals\|raw/394-ruger-2020-oligonucleotides-to-the-gene-rescue-fda-approvals]])

## ALS 치료제 개발

- **STMN2 교정**: TDP-43 핵 손실 → STMN2 cryptic exon 포함 → 비정상 polyadenylation → ASO로 정상 스플라이싱 회복 ([[Jay's Knowledge Base/raw/446-baughn-2023-mechanism-of-istmn2i-cryptic-splice-polyadenylatio\|raw/446-baughn-2023-mechanism-of-istmn2i-cryptic-splice-polyadenylatio]], [[Microbiome-KB/raw/354-melamed-2019-premature-polyadenylation-mediated-loss-of-stathmi\|raw/354-melamed-2019-premature-polyadenylation-mediated-loss-of-stathmi]], [[Microbiome-KB/raw/355-klim-2019-als-implicated-protein-tdp-43-sustains-levels-of-s\|raw/355-klim-2019-als-implicated-protein-tdp-43-sustains-levels-of-s]])
- **UNC13A 교정**: ALS/FTD 위험 SNP가 TDP-43 결합 부위에 위치 → cryptic exon 포함 촉진 → ASO 치료 표적 ([[Jay's Knowledge Base/raw/328-brown-2022-tdp-43-loss-and-als-risk-snps-drive-mis-splicing-a\|raw/328-brown-2022-tdp-43-loss-and-als-risk-snps-drive-mis-splicing-a]], [[Jay's Knowledge Base/raw/329-ma-2022-tdp-43-represses-cryptic-exon-inclusion-in-the-ftd\|raw/329-ma-2022-tdp-43-represses-cryptic-exon-inclusion-in-the-ftd]], [[Microbiome-KB/raw/352-chen-2022-unc13a-gene-brings-new-hope-for-als-disease-modify\|raw/352-chen-2022-unc13a-gene-brings-new-hope-for-als-disease-modify]])
- **FUS 침묵**: FUS 돌연변이 ALS에서 ASO 매개 FUS 발현 감소 전략 ([[Jay's Knowledge Base/raw/430-korobeynikov-2022-antisense-oligonucleotide-silencing-of-fus-express\|raw/430-korobeynikov-2022-antisense-oligonucleotide-silencing-of-fus-express]])
- **Ataxin-2 감소**: TDP-43 마우스 모델에서 수명 연장, 병리 감소 확인 ([[Microbiome-KB/raw/359-becker-2017-therapeutic-reduction-of-ataxin-2-extends-lifespan\|raw/359-becker-2017-therapeutic-reduction-of-ataxin-2-extends-lifespan]])
- ALS 임상 파이프라인 확대 추세 ([[Microbiome-KB/raw/344-koch-nd-als-looks-up-as-clinical-pipeline-explodes\|raw/344-koch-nd-als-looks-up-as-clinical-pipeline-explodes]], [[Microbiome-KB/raw/415-klim-2019-antisense-oligonucleotide-therapies-for-amyotrophi\|raw/415-klim-2019-antisense-oligonucleotide-therapies-for-amyotrophi]])
