# Bimagrumab (비마그루맙) — BELIEVE Phase 2b 임상 결과

## 배경

- **Eli Lilly**가 **19억 달러**에 Versanis Bio를 인수하여 항-ActRII 항체 **비마그루맙(bimagrumab)** 확보
- GLP-1 수용체 작용제의 최대 약점인 **근육 소실(lean mass loss)** 문제를 해결하기 위한 병용 전략

## BELIEVE 임상 개요

| 항목 | 내용 |
|------|------|
| 임상 단계 | Phase 2b |
| ClinicalTrials.gov | [NCT05616013](https://clinicaltrials.gov/study/NCT05616013) |
| 디자인 | 이중맹검, 위약대조, 무작위 배정 |
| 대상 | 비만 성인 507명, 9개 그룹 |
| 투여 기간 | 48주 |
| 투여 방법 | Bimagrumab IV q12w + Semaglutide SC qw |

## 주요 결과 (48주)

| 그룹 | 체중 변화 | 비고 |
|------|-----------|------|
| 위약 | −3.3 kg | — |
| Bimagrumab 30 mg/kg 단독 | −9.3 kg | p < 0.001 vs 위약 |
| Semaglutide 2.4 mg 단독 | −14.2 kg | p < 0.001 vs 위약 |
| **Bima 30 + Sema 2.4 병용** | **−17.8 kg** | p < 0.001 vs 위약 |

### 체성분 변화 (핵심)

- 병용군: 체중 **22.1% 감소**, 그 중 **92.8%가 지방**에서 감소
- Semaglutide 단독: 지방 감소 비율 **71.8%**
- → 병용 시 **근육량(lean mass) 보존 효과**가 극적으로 향상

## 시사점

- "GLP-1 + 근육 보호"는 단순 부작용 관리가 아닌 **수십억 달러 규모의 새로운 시장 카테고리**
- Eli Lilly는 자사 tirzepatide(모운자로)와의 병용도 추진 가능 → 파이프라인 시너지

## Bimagrumab 단독 투여 시 체중 감소 메커니즘

### ActRII 경로의 이중 역할

ActRII(Activin Type II Receptor) 신호는 근육뿐 아니라 **지방 조직에도 작용**한다.

| 조직 | ActRII 신호 활성 시 | Bimagrumab으로 차단 시 |
|------|---------------------|----------------------|
| **골격근** | 근육 성장 억제 (myostatin/activin 경로) | → **근육량 증가** (anabolism ↑) |
| **지방 조직** | 지방세포 분화·축적 촉진 | → **지방량 감소** (adipogenesis ↓) |

ActRII를 차단하면 근육은 **늘어나고**(lean mass ↑), 지방은 **줄어드는**(fat mass ↓) 두 가지가 동시에 발생한다.

### 순(net) 체중 감소 원리

지방 감소 폭 > 근육 증가 폭이므로 순 체중은 감소한다.

$$
\Delta BW = \underbrace{(-\text{Fat mass})}_{\text{큰 음수}} + \underbrace{(+\text{Lean mass})}_{\text{작은 양수}} < 0
$$

BELIEVE에서 bimagrumab 30 mg/kg 단독의 **−9.3 kg**은 대부분 지방에서 빠진 것이며, 근육은 유지 또는 소폭 증가했다.

### 추가 기전: 기초대사율 상승

근육량 증가 → **기초대사율(BMR) 상승** → 안정 상태에서 에너지 소비 증가 → 간접적 지방 연소 가속

### 선행 임상 근거

2021년 비만 + 제2형 당뇨 환자 대상 Phase 2 (*JAMA Network Open*):
- 지방량 **−20.5%** 감소
- 근육량 **+3.6%** 증가
- 순 체중 감소 달성

> [!tip] 요약
> 비마그루맙은 "살 빠지는 약"이 아니라 **"지방→근육 체성분 리모델링 약"**에 가깝다. 지방 감소 > 근육 증가이므로 체중계 숫자도 내려간다. 세마글루타이드와 병용 시, 세마글루타이드가 식욕·체중을 줄이고 비마그루맙이 감소분을 지방 쪽으로 몰아주는 시너지가 작용한다.

현재 **Phase 2** 단계이며, 아직 Phase 3에는 진입하지 않았다.

### 주요 동향

- **BELIEVE (semaglutide 병용)**: 완료 → Nature Medicine 논문 발표
- **Tirzepatide 병용 (비당뇨)**: 현재 진행 중, 2026년 4월 완료 예정 — Lilly 자사 약물(Zepbound)과의 조합이 핵심 전략
- **Tirzepatide 병용 (당뇨 포함)**: 등록 시작 전 **철회** — 비당뇨 비만 시장에 집중하거나 파이프라인 우선순위 재조정 신호
- **동시제형(coformulation) Phase 1 완료**: Bimagrumab + tirzepatide를 하나의 주사제로 합치는 연구 → 편의성 확보 의도

> [!warning] Phase 3 전망
> Phase 3 진입 여부는 현재 진행 중인 tirzepatide 병용 Phase 2 결과(2026년 상반기)에 달려 있다. 당뇨 동반 비만 임상 철회는 개발 전략 변경 가능성을 시사한다.
