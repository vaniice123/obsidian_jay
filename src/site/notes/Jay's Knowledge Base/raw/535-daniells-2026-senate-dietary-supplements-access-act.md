# 미국 상원, 건강보조식품의 HSA·FSA 사용 허용 법안 발의 (Dietary Supplements Access Act, 2026)

## 한 줄 요약

미국 상원이 건강보조식품(dietary supplements)을 적격 의료비(qualified medical expense)로 인정해 HSA·FSA·HRA·Archer MSA 등 세제 우대 의료저축계좌로 구매할 수 있게 하는 「Dietary Supplements Access Act」를 발의했다. 2026-12-31 이후 지출분부터 적용(사실상 2027-01-01~), 연 한도 **1인당 $500**(부부 별도신고 시 $250), **에너지·청량·탄산음료는 명시적 제외**.

## 법안 개요

| 항목 | 내용 |
|------|------|
| 법안명 | Dietary Supplements Access Act |
| 의회 | 119th Congress, 2nd Session |
| 발의자 | Sen. Kevin Cramer (R-ND), Sen. John Curtis (R-UT) |
| 발의일 | 2026-05-20 |
| 핵심 조치 | Internal Revenue Code 개정 → 건강보조식품을 적격 의료비로 지정 |
| 적용 계좌 | HSA(§223 개정), Archer MSA(§220 개정), FSA·HRA(§106 신설 (h)항) |
| 연간 한도 | **일반 $500 / 부부 별도신고(MFS) 시 $250** |
| 시행 시기 | 2026-12-31 이후 지출분부터 (사실상 2027-01-01~) |
| 입법 형태 | 초당적·양원 동시 발의 (하원 동반 법안 별도) |

하원 동반 법안 발의자: Darin LaHood (R-IL-16), Brendan Boyle (D-PA-2), Claudia Tenney (R-NY-24), Josh Gottheimer (D-NJ-5).

> [!warning] 기사 본문 정정
> NutraIngredients 기사는 한도를 "개인 $250 / 부부 합산 $500"으로 보도했으나, 법안 원문(MCG26481 86P) 확인 결과 **기본 $500, 부부 별도신고 시 $250**이다. 즉 $250 은 "합산"이 아니라 "별도신고"에 적용되는 축소 한도다.

## 대상 정의 및 제외 품목 (법안 원문 §2(a)(2) "(E)" 신설)

- **정의**: "dietary supplement"는 **연방 식품·의약품·화장품법 §201(ff) (21 U.S.C. 321(ff))** 의 정의를 그대로 차용.
- **명시적 제외 (Exclusion)**:
  > 에너지 드링크(energy drink), 청량음료(soft drink), 탄산음료(soda)로 판매·표시되거나 일반적으로 그렇게 인식되는 제품은 본 법의 dietary supplement 정의에서 제외된다.
- 즉 품목 차원에서 콕 집어 배제되는 것은 위 **3종 음료**뿐이며, 그 외 FDA 정의에 부합하는 건강보조식품 전반이 적용 대상이다.

> [!note] 입법기술적 참고
> 정의 조항은 §223(d)(2)에 (E)로 신설되지만, FSA·HRA 신설 조항(§106(h))과 Archer MSA 개정 조항이 이를 각각 §223(d)(2)(D), §220(d)(2)(E)로 잘못 교차참조하고 있다. 단순 드래프팅 오류로 입법 과정에서 정정될 전망.

## 추진 배경

- **현행 규제**: IRS Publication 502 (2000년 개정)으로 의사 처방 없는 건강보조식품은 HSA/FSA 사용 대상에서 제외돼 왔다. 자외선차단제·반창고·콘택트렌즈 용액 등은 처방 없이 사용 가능.
- **시장 규모**: 미국인 약 4,000만 명 HSA(약 1,470억 달러) 보유, 3,700만 명 직장 FSA 보유.
- **이전 시도**: 동일 취지 법안이 2023년 하원 H.R. 4794, 상원 S. 3172 로 발의됐으나 모두 입법에 실패. 본 법안은 재추진.
- 지난해 업계 단체들은 IRS 에 세법 개정을 요청하는 서한을 발송한 바 있음.

## 의원·업계 입장

- **Sen. Cramer**: "영양보조제는 중요한 예방적 관리 수단으로, 장기적으로 의료비를 낮춘다. HSA·FSA 사용 방식의 현대화가 필요하다."
- **Sen. Curtis**: "보조식품 접근성 확대는 'Make America Healthy Again'의 핵심이며 개인의 건강 주도권을 강화한다."
- 지지 단체: **NPA, CRN, CHPA** 등 주요 건강보조식품 협회 모두 지지.
  - CRN (Steve Mister): 다른 의료비와 동일한 세제 우대 도구 활용을 가능케 하는 '상식적 개혁'.
  - CHPA (Scott Melville): 보조식품 사용을 뒷받침하는 과학이 늘어나는 시점에 합리적 의료 정책.
  - NPA (Daniel Fabricant): 현행 세법이 보조식품을 '사치품'으로 취급하는 문제를 지적, 신속한 입법 촉구.

## 시사점 (건기식·마이크로바이옴 산업 관점)

- 미국 건강보조식품 수요 측 자극 요인 — HSA(약 1,470억 달러)·FSA 자금이 OTC 보조식품 구매에 사용 가능해지면 카테고리 전반의 가격 민감도가 완화된다.
- 프로바이오틱스·포스트바이오틱스 등 마이크로바이옴 기반 건기식도 (FDA 의 dietary supplement 정의 충족 시) **적용 대상에 포함**될 가능성이 높다.
- 한국 건기식 수출자 입장에서는 미국 시장 진입 후 NDI·NSF 등 사전 인증 부담은 여전하나, 통과 이후 가격 접근성은 개선되는 흐름.
- 다만 본 법안은 119th Congress 발의 단계로, 2023년 동일 취지 법안이 좌초된 바 있어 통과는 불확실.
